1. **检查原始数据与坐标范围。** 四个ZIP各点位均有四方向图片，按中心表精确匹配后缩减为13,660点位。发现不同坐标可能有完全相同的图片；后续训练验证需防止跨集合重复。
2. **建立50点位标注页面。** 道路等级抽样13/13/12/12，种子20261012；四张并排、a/b选择、本地自动保存、CSV导出与原ZIP读取。人工选择30组0/180、20组90/270，固定角度规则不成立。
3. **CLIP零样本基线。** 相反方向配对44/50一致，逐张取最高两张28/50。对6个不一致逐组查看；人工确认其中一个明确错误，其余有不确定性。保留原标签，不将不一致自动替换为模型答案。
4. **100点位独立验证。** 种子20261013、各等级25组；排除原50坐标并检查没有相同图片。先冻结预测，再盲标，新增确定/勉强按钮。84个确定组77一致，16个勉强组8一致。
5. **轻量分类器试验。** 使用84个确定点位，固定CLIP特征＋L2逻辑回归。5折按点位验证，每点位仅计一次折外预测；81/84一致，比零样本77/84高4.8个百分点。修正6个原错误、新增2个错误。未按这些结果搜索超参数。
6. **30点位最终独立测试。** 种子20261013030，等级8/8/7/7；排除此前150坐标和相同图片。使用全部84点位训练的冻结分类器，先预测后标注。25个确定组24一致（96%）；5个勉强组2一致（40%）；总26/30一致。未据此重训或调规则。
7. **建立公开项目仓库。** 项目名称覆盖后续VLM分析。发布代码、方法、迭代记录和去除逐点信息的汇总指标。全量推理与VLM尚未运行。
8. **全量中心点位初筛。** 冻结现有CLIP＋轻量分类器，处理13,660点位、54,640张输入图，输出27,320个图片引用。110点位沿用确定人工选择，11,170为模型自动选择，2,380待复核。复核规则为分类器两对分差小于0.3、与原零样本配对不一致或既有不确定标注；该规则仅用于安排复核。支持SQLite断点续跑和图片字节重复缓存。检查点位覆盖、两张引用、原ZIP成员和人工覆盖。成功全量推理约626.8秒，未包含准备、检查与人工复核耗时。VLM尚未运行。
