# 方法

## 研究对象与筛选定义

四个道路等级原始数据包含26,295个点位、105,180张图片。中心点位名单包含13,660个唯一坐标，全部精确匹配、道路等级一致，每点位都有四个方向。

中心点位筛选排除50,540张图片（48.05%），剩54,640张待方向识别。按每点位选两张计算，最终预期27,320张；这不是已完成的全量输出。

侧向照片主要朝向路侧建筑、商铺、围墙或植被。沿街照片主要沿道路看向远处。道路面积、商铺或植被是否出现不能单独决定类别。路口、斜向道路、院落和高架下可能没有唯一明确的侧向组合。

## 零样本基线

使用 `openai/clip-vit-base-patch32`。完整RGB画面缩放并用灰色补边到224×224，避免中心裁剪丢失左右信息。固定四条侧向描述、四条沿路描述；分数为侧向描述平均余弦相似度减沿路描述平均相似度。

比较两对相反方向的总分，选择0/180或90/270。该分数及两对分差均不是校准后的正确概率。模型未用样本标注训练或调提示词。

首批50组中，直接取独立图片分数最高两张仅28/50一致；配对约束为44/50。这是该批数据的描述性比较。

## 轻量分类器

保持CLIP图像编码器冻结，提取512维单位归一化特征。训练带L2正则的逻辑回归：`C=1`、`solver=lbfgs`、`max_iter=1000`，不做特征缩放或超参数搜索。图片标签为侧向/沿路，每个确定点位各两张。

选择阶段对每对图片的分类器决策分数求和，保留总分较高的一对。决策分差与CLIP余弦分差尺度不同，不能共用阈值。

训练数据仅为第二轮100点位中84个确定点位。16个勉强点位不作为可靠训练答案；第一批50组未系统标记确定程度，也不混入训练。

## 训练与验证

采用按点位划分的5折分组交叉验证，固定随机种子20261013，按所选方向对尝试分层。同点位四张图保持在同一折；共享字节完全相同图片的点位合并成同一组，再划分。该84点位未检出重复图片组。

每个点位恰好验证一次，报告的是未参与该轮训练时的预测。分类器81/84，原基线77/84；修正6个原错误，新增2个错误，净提升4组。最终另用全部84点位训练权重供后续独立测试，这个全数据模型不用于产生上述折外指标。

第三轮从中心点位抽30个全新点位（道路等级8/8/7/7），排除前150坐标及相同图片。先保存冻结分类器预测及权重SHA256，再让人工盲标。确定组24/25一致，勉强组2/5一致。

## 标注与交付字段

标注界面允许任意两张选择，第一次为side_a，第二次为side_b。名称不表示实际左右；改变顺序不改变整组一致率。

每条清单包含：`sample_id`、`point_id`、`road_level`、`archive`、`status`、两侧的角度、原文件名、实际ZIP成员名，以及`note`。成员名保留原ZIP编码结果，读取脚本直接引用该成员，避免重新解压时中文目录名变化。

`confirmed` 为确定选择，`needs_review` 为勉强候选，`draft` 为未确认编辑，未标注为`unlabeled`。图片与ZIP均不被标注操作修改。

## 局限与后续质量检查

样本按道路等级分层，不能直接用未加权样本比例估计全量总体准确率。确定程度来自人工声明，不是客观真值保证。附近点位可能包含相似场景；当前未按街区或空间邻域留出。

独立测试仅25个确定点位，96%不是全量质量保证。勉强组存在定义歧义。低分差可用于复核排序，但阈值必须另行验证；大分差不能自动证明正确。

参考：[CLIP文档](https://huggingface.co/docs/transformers/model_doc/clip)、[分组交叉验证](https://scikit-learn.org/stable/modules/cross_validation.html)、[逻辑回归](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LogisticRegression.html)。
